## 📌 Project Overview
This project explores the concept of digital literacy through a series of practical tasks focused on communication, collaboration, online presence, and cybersecurity awareness. Each task involved using real digital tools and reflecting on their applications in academic and professional contexts.

## 🧠 Module Summary

### Task 1 – Infographic
Created a visual representation of digital literacy concepts using Canva, focusing on safe practices, useful tools, and professional online presence.

### Task 2 – Digital Portfolio
Set up and updated profiles on GitHub, LinkedIn, and Kaggle to establish a professional digital presence.

### Task 3 – Platforms
Practiced coding on HackerRank and created a Digital Literacy Awareness Quiz using Google Forms.

### Task 4 – Email Etiquette
Drafted professional emails and created a social media do’s and don’ts checklist to understand responsible communication.

### Task 5 – Cyber Awareness
Explored phishing through a case study and developed awareness resources, including a prevention checklist and an interactive visual novel concept.
